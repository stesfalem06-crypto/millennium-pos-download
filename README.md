# Millennium POS for Mac

Inventory & POS for Millennium boutique, Asmara.

Download from **Releases**:
- **Millennium-mac-arm64.zip** for Apple Silicon Macs (M1–M4)
- **Millennium-mac-x64.zip** for Intel Macs

Unzip, drag Millennium to Applications, right-click and choose Open the first time. If blocked: `xattr -cr /Applications/Millennium.app`
